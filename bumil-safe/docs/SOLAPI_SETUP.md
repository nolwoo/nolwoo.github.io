# 카카오 알림톡 연결 가이드 (새 상담 알림)

새 상담이 들어오면 사장님 카톡으로 알림이 가도록 만드는 작업입니다. **카카오톡 채널이 아직 없어서, 이번엔 두 단계**를 거쳐야 합니다.

1. 카카오톡 비즈니스 채널 만들기 (홈페이지 "카카오톡 상담" 버튼도 이걸로 살아남 — 지금은 "준비 중"으로 뜸)
2. 그 채널을 솔라피(SOLAPI)에 연동해서 알림톡 발송

전체 약 30분 + 카카오 심사 대기(영업일 1~3일).

## 1) 카카오톡 채널 만들기 (아직 없다면)

1. https://center-pf.kakao.com 접속 → 카카오 계정으로 로그인
2. **채널 만들기** → 검색용 아이디(예: `bumilsafe`), 채널명(예: "범일금고 영등포대리점"), 카테고리 선택 → 생성
3. 만들어진 채널 **관리자센터 → 채널 → 상세설정**에서 **"채널 홈 URL"**을 복사해 둡니다 (`pf.kakao.com/_xxxxx` 형태) — 이건 홈페이지 상담 버튼에 쓸 값입니다.

이미 매장용 카카오톡 채널이 있다면 이 단계는 건너뛰고 채널 홈 URL만 복사해오면 됩니다.

## 2) 솔라피 가입 + 사업자 인증

1. https://solapi.com 가입
2. **설정 → 사업자 인증** (또는 가입 중 안내되는 인증 단계)에서 사업자등록증 업로드 → 인증 대기
   - 개인사업자도 가능. 인증 없이도 가입은 되지만, 카카오 알림톡 발송은 인증 후 가능합니다.

## 3) 카카오 채널을 솔라피에 연동

솔라피 대시보드 → **카카오 → 채널 관리** (메뉴명은 콘솔 개편 시 바뀔 수 있음, "채널" 또는 "비즈니스 채널"로 찾으면 됨)
1. **채널 연동/추가** → 1)에서 만든 카카오톡 채널 검색·선택
2. 카카오톡 채널 관리자센터 쪽에서 연동 승인 요청이 뜨면 승인 (관리자센터에 다시 로그인해서 확인해야 할 수 있음)
3. 연동이 끝나면 **발신프로필 ID(pfId)** 가 발급됨 — 이 값을 나중에 `.env.local`의 `SOLAPI_PFID`에 넣습니다.

> 이미 다른 문자 발송 플랫폼(비즈엠, 알리고 등)에 연결된 채널이면 거기서 먼저 연동을 끊어야 솔라피에 새로 연동할 수 있습니다. 신규 채널이면 해당 없음.

## 4) 알림톡 템플릿 등록·심사

솔라피 대시보드 → **카카오 → 템플릿**
1. **템플릿 추가** → 연동한 채널 선택, 카테고리 선택(상담/예약 접수 안내류)
2. 아래 문구를 그대로 붙여넣기 (변수명이 코드와 정확히 일치해야 함 — `lib/notify.ts`에서 이미 이 4개 변수로 보내도록 구현돼 있음):

```
[범일금고 영등포대리점] 새 상담 접수

이름: #{이름}
연락처: #{연락처}
관심제품: #{관심제품}
접수시각: #{접수시각}

관리자 페이지에서 전체 내용을 확인해 주세요.
```

3. **검수 요청** 클릭 → 카카오 심사 대기 (보통 영업일 1~3일, 카카오가 심사 주체라 정확한 기한 보장은 안 됨)
4. 심사 통과하면 템플릿 상태가 "승인"으로 바뀌고, 이때 **템플릿 ID**가 나옵니다 → `SOLAPI_TEMPLATE_ID`에 사용

## 5) 발신번호 등록

솔라피 대시보드 → **발신번호 관리**
1. 매장 전화번호(02-2632-6070) 또는 사장님 번호로 등록 신청
2. 본인確인(통신사 인증 또는 서류) 절차 진행 — 등록된 번호만 발신 가능
3. 승인된 번호를 `SOLAPI_SENDER_PHONE`에 사용

## 6) API 키 발급

솔라피 대시보드 → **설정 → API 키 관리**
- **API Key**, **API Secret** 발급 → 각각 `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`

## 7) `.env.local` 채우기

프로젝트 루트 `bumil-safe/.env.local`에 다음을 채웁니다 (이미 자리는 만들어져 있음):

```
SOLAPI_API_KEY=발급받은값
SOLAPI_API_SECRET=발급받은값
SOLAPI_PFID=3)에서 발급된 발신프로필ID
SOLAPI_TEMPLATE_ID=4)에서 승인된 템플릿ID
SOLAPI_SENDER_PHONE=5)에서 등록한 번호
INQUIRY_NOTIFY_PHONE=알림을 받을 사장님 휴대폰번호
```

그리고 홈페이지 "카카오톡 상담" 버튼을 살리려면 `lib/site.ts`의 `kakaoUrl`에도 1)에서 복사한 채널 홈 URL을 넣어야 합니다.

## 8) 테스트

1. dev 서버 재시작 (환경변수는 재시작해야 반영됨)
2. `/contact`에서 상담 폼 제출
3. 사장님 카톡(`INQUIRY_NOTIFY_PHONE`)으로 알림톡이 오는지 확인
4. 혹시 안 오면 서버 로그에서 `alimtalk failed` 에러 메시지 확인 — 실패해도 자동으로 이메일(Brevo)로 대체 발송되니 상담 자체는 놓치지 않습니다.

## 배포할 때 (Vercel)

위 6개 환경변수(`SOLAPI_*`, `INQUIRY_NOTIFY_PHONE`)를 **Vercel 프로젝트 Settings → Environment Variables**에도 동일하게 넣어야 실제 서비스에서 동작합니다.

## 참고

- 알림톡 발송은 솔라피 요금제에 따라 건당 과금됩니다 (무료 플랜엔 보통 소량 크레딧 제공). 잔액 소진 시에도 이메일로 자동 대체되므로 상담을 놓치는 일은 없습니다.
- 메뉴 이름·위치는 솔라피/카카오 콘솔 개편으로 바뀔 수 있습니다. 이 문서와 다르면 "채널", "발신번호", "템플릿" 같은 키워드로 대시보드 내에서 찾아보세요.
