# 도메인 연결 가이드 (bumilsafe-ydp.co.kr)

가비아에서 `bumilsafe-ydp.co.kr`을 사서 Vercel(현재 배포된 사이트)에 연결하는 순서입니다. 약 20분 + DNS 전파 대기(보통 수분~1시간, 최대 48시간).

## 1) 가비아에서 도메인 구매

1. https://domain.gabia.com 접속 (계정 없으면 가입 — 이메일/휴대폰 인증만으로 개인도 `.co.kr` 등록 가능, 사업자등록증 필수 아님)
2. 검색창에 `bumilsafe-ydp.co.kr` 입력 → 사용 가능 확인 → **담기**
3. 등록 기간 선택(1년 또는 그 이상) → 결제 (카드/계좌이체/카카오페이)
4. 소유자 정보 입력 시 실제 매장 정보(상호·연락처·주소) 사용 — 나중에 WHOIS 조회 시 노출되는 정보이니, 개인정보 보호 옵션(있다면)을 켜는 걸 권장

구매가 끝나면 **My가비아 → 서비스 관리**에서 방금 산 도메인이 보입니다.

## 2) Vercel 프로젝트에 도메인 추가

1. https://vercel.com 대시보드 → bumil-safe 프로젝트 선택
2. **Settings → Domains** → **Add Domain**
3. `bumilsafe-ydp.co.kr` 입력 → 추가
4. Vercel이 `www.bumilsafe-ydp.co.kr`도 같이 추가하라고 권장할 텐데, **같이 추가**하는 걸 권장 (누가 www 붙여서 접속해도 정상 작동하도록)
5. 추가하면 Vercel이 화면에 **A 레코드 값(IP)**과 **CNAME 값**을 보여줍니다 — 이 값은 프로젝트마다 다르고 바뀔 수 있으니, 아래 3단계에서 반드시 **이 화면에 뜬 값을 그대로** 복사해서 씁니다 (다른 글·과거 스크린샷의 값을 베끼면 안 됨).

## 3) 가비아에서 DNS 레코드 입력

1. **My가비아 → 서비스 관리 → 해당 도메인 → DNS 정보(또는 "DNS 관리")**
2. 레코드 2개 추가:
   - **A 레코드**: 호스트 `@` (또는 빈칸), 값 = 2단계에서 Vercel이 보여준 IP 주소
   - **CNAME 레코드**: 호스트 `www`, 값 = 2단계에서 Vercel이 보여준 CNAME 값
3. 저장

## 4) 확인

1. Vercel **Settings → Domains**로 돌아가서 상태가 "Valid Configuration"(정상 연결)으로 바뀔 때까지 기다림 (보통 수분, 길면 몇 시간)
2. `https://bumilsafe-ydp.co.kr` 접속해서 사이트가 뜨는지 확인
3. `https://www.bumilsafe-ydp.co.kr`도 접속해서 정상 연결(또는 apex로 리다이렉트)되는지 확인

## 5) 도메인 연결 후 반드시 해야 하는 후속 작업

도메인만 연결한다고 끝이 아닙니다 — 아래 2가지를 안 하면 각각 지도가 깨지거나 검색 노출이 옛 주소로 흩어집니다.

### 5-1. 카카오 개발자 콘솔에 새 도메인 등록 (지도 깨짐 방지)
1. https://developers.kakao.com → 내 애플리케이션 → 해당 앱 선택
2. **앱 설정 → 플랫폼 → Web** → 사이트 도메인에 `https://bumilsafe-ydp.co.kr` **추가** (기존 `https://bumil-safe-next.vercel.app`은 지우지 말고 남겨둬도 무방)
3. 안 하면 `/contact` 페이지의 카카오맵이 새 도메인에서 안 뜹니다.

### 5-2. `NEXT_PUBLIC_SITE_URL` 환경변수 교체
- `.env.local`과 **Vercel 프로젝트 Settings → Environment Variables** 양쪽에서 `NEXT_PUBLIC_SITE_URL`을 `https://bumilsafe-ydp.co.kr`로 바꿔야 sitemap·canonical·OG 태그가 새 도메인으로 갱신됩니다.
- Vercel 쪽 값을 바꾼 뒤엔 **재배포(Redeploy)**가 필요합니다.

### 5-3. (도메인 안정화 후) 검색엔진 재등록
- 네이버 서치어드바이저 + 구글 서치콘솔에 새 도메인으로 **다시** 소유확인·사이트맵 제출이 필요합니다 (도메인이 바뀌면 이전 등록은 무효). 이건 도메인이 며칠 안정적으로 뜬 뒤 진행하면 됩니다 — 지금 당장 급한 건 아닙니다.

## 참고
- 가비아 화면 메뉴명은 개편되면 바뀔 수 있습니다. "DNS 관리" 또는 "네임서버 관리"라는 이름으로 찾으면 됩니다.
- Hobby 플랜 기준 프로젝트당 커스텀 도메인 50개까지 허용되므로 개수 제한 문제는 없습니다.
