# 홈 히어로 풀블리드 리디자인 (2026-08-08)

## 시작 계기

헤더 상담 버튼(카카오톡·전화)을 나란히 보다가 카카오 옐로우 풀필 배경만 흑백 모노톤
무드와 어긋나는 걸 발견 → 카카오 배경을 아웃라인(테두리만)으로 바꾸고 아이콘 색으로만
브랜드를 인지시키는 쪽으로 정리(`bba06c9` 다음 커밋). 이 작업을 계기로 "화면을 꽉 채우는
히어로로 가면 어떨까"로 논의가 확장됨.

## 검토한 방향

레퍼런스: [ilhada.com](https://www.ilhada.com)(풀블랙 타이포 히어로), 본사 사이트
[bumilsafe.co.kr](https://bumilsafe.co.kr)(피크 캐러셀 — 좌우로 다음 슬라이드가 살짝
보이는 고정 박스형, 화면 전체를 채우지 않음), Patek Philippe(에디토리얼 레이아웃 —
좌측 정렬 텍스트, 우측 세로 인디케이터, 헤더가 사진 위에 투명하게 얹힘).

시안 4개를 실제 사이트 사진·폰트·색으로 프로토타입해서 비교:

| 안 | 내용 | 결과 |
|---|---|---|
| A | 타이포 중심 풀블랙(사진 없음) | 기각 — "사진/제품이 주인공" 원칙과 어긋남 |
| B | 정적 사진 1장 풀블리드, 중앙 정렬 | 대안으로 유지(리스크 최저) |
| C | 기존 5장 오토슬라이드를 풀블리드로, 중앙 정렬 | 1차 채택 |
| D | C + 좌측 정렬 텍스트 + 우측 세로 인디케이터 + CTA 단순화 | **최종 채택** |

## 최종 결정 (D)

- 기존 5장 제품 캐러셀(오토슬라이드, `prefers-reduced-motion` 존중)을 그대로 유지하되
  화면 전체(100dvh)를 채우도록 확장.
- 텍스트 블록을 하단-좌측 정렬로 변경, 오른쪽 제품 사진이 가려지지 않게 좌→우 그라데이션만 적용.
- 슬라이드 인디케이터를 하단 중앙 점 → 우측 세로 점으로 이동(텍스트·CTA와 자리 안 겹치게).
- 히어로 안의 CTA를 카카오+전화 두 버튼에서 얇은 텍스트 링크("상담 안내 보기 →") 하나로 단순화.
  상시 상담 CTA는 헤더가 담당하므로 히어로 안에서 반복할 필요가 없다는 판단.
- **헤더를 홈 히어로 위에서만 투명하게 띄움** — 스크롤로 히어로를 벗어나면(대략 뷰포트
  80% 지점) 원래의 불투명 고정 헤더로 자연스럽게 전환. 다른 페이지는 항상 기존 방식 그대로.

## 기술 변경

- `components/HeroCarousel.tsx` — 풀블리드(100dvh)로 재작성. 좌측 정렬 텍스트, 우측
  세로 인디케이터, `-mt-14`(헤더 높이만큼 음수 마진)로 헤더 아래에 사진이 이어지게 tuck.
  페이지 대표 h1(SEO용 "Bumil Safe · 영등포 금고 전문점")은 컴포넌트 안으로 이동, 슬라이드
  제목은 그대로 h2.
- `components/Header.tsx` — `usePathname()`으로 홈 여부, `scrollY`로 스크롤 여부를 판단해
  히어로 위에서만 투명(로고·내비·버튼 흰색) → 스크롤 시 기존 불투명 스타일로 전환.
- `components/Button.tsx` — 다크 배경용 아웃라인 버튼 변형 `ghost-dark`/`kakao-dark` 추가.
  (헤더가 투명해지면 기존 잉크색 아웃라인 버튼이 안 보이는 버그가 있었음 — 이걸로 해결.)
- `components/ConsultButtons.tsx` — `onDark` 여부에 따라 카카오·전화 버튼이 다크용
  아웃라인 변형을 쓰도록 분기.
- `app/page.tsx` — 히어로 섹션을 감싸던 `Container`/구식 h1 제거, `<HeroCarousel />`
  단독 렌더로 교체.

## 남은 확인 사항

- **모바일 화면 육안 확인 안 됨** — 이번 세션에서 브라우저 자동화 리사이즈가 동작하지
  않아 실기기/반응형 미리보기로 직접 확인 필요. 반응형 클래스(`sm:` 브레이크포인트)는
  기존 캐러셀과 동일한 패턴이라 크게 문제될 소지는 낮지만, 배포 전 폰으로 한 번 보는 게 안전.
