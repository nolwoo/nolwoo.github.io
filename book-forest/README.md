# 인생책숲 홈페이지

부모의 인생을 공유하는 독서모임 플랫폼 '인생책숲'의 안내 사이트입니다.
기획 배경과 전체 요구사항은 [`PRD.md`](./PRD.md)를 참고하세요.

## 새 기수 올리는 법 (개발 지식 없이 가능해요)

모임 내용은 `data/programs.js` 파일 하나에만 들어 있어요. 이 파일만 고치면
홈 화면과 모임 안내 페이지가 모두 자동으로 갱신됩니다.

1. GitHub 웹사이트에서 이 저장소의 `book-forest/data/programs.js` 파일을 엽니다.
2. 연필 아이콘(✏️, Edit this file)을 눌러 편집 모드로 들어갑니다.
3. 파일 맨 아래 **"새 기수 템플릿"** 블록을 통째로 복사합니다.
4. `PROGRAMS = [` 바로 다음 줄에 붙여넣고, 값들을 실제 정보로 바꿉니다.
   - `status`는 반드시 `"모집중"` `"모집마감"` `"진행중"` `"종료"` 중 하나로 씁니다.
   - 모르는 값은 빈칸으로 두지 말고 `"확인 중"`이라고 적어주세요.
5. 지난 기수를 지우지 마세요. 끝났으면 그 항목의 `status`만 `"종료"`로 바꾸면
   "모임 안내" 페이지의 운영 기록으로 남습니다.
6. 화면 아래 **"Commit changes..."** 버튼을 눌러 저장합니다.
7. 1~2분 뒤 사이트에 반영됩니다. (배포는 GitHub Pages 또는 Vercel — 실제 운영 배포처에 따라 확인)

같은 방식으로 `data/reviews.js`를 고치면 후기도 바꿀 수 있어요.

## 로컬에서 미리보기

```bash
cd book-forest
python3 -m http.server 8010
# 브라우저에서 http://localhost:8010 접속
```

## 파일 구조

```
book-forest/
  index.html       홈
  programs.html     모임 안내 (전체 목록 + 필터)
  about.html        인생책숲 소개
  data/
    programs.js     모임 데이터 — 운영자가 직접 수정하는 파일
    reviews.js       후기 데이터
  styles.css        디자인 (하나의숲과 같은 팔레트, 조금 더 차분한 톤)
  script.js         데이터를 화면에 그리는 스크립트 + 모바일 메뉴
```

## 현재 상태

이 시안은 **레이아웃과 구조 확인용**입니다. `data/programs.js`,
`data/reviews.js`의 내용은 예시이며, `PRD.md` 8-1장 "운영자 확정 필요" 항목이
채워진 뒤 실제 내용으로 교체합니다.
