# 상명피아노음악교습소 — 홈페이지 시안

지인이 운영하는 인천 검단구 마전동 상명피아노음악교습소 홈페이지 **제안 시안**입니다.
자세한 배경·확인 목록은 [`PRD.md`](./PRD.md) 참고.

- **역할**: 유입은 네이버 블로그(`blog.naver.com/byeoldabang_mh`)와 네이버 플레이스가 담당하고,
  이 페이지는 그렇게 유입된 방문자를 실제 문의(구글 폼 제출)로 전환시키는 것만 담당합니다.
  검색 노출을 위한 작업(도메인, 네이버 웹마스터도구 등)은 범위 밖입니다.
- **구조**: 빌드 없는 정적 파일 `index.html` 하나. 원페이지 + 앵커 메뉴.

## 로컬에서 보기

```bash
python3 -m http.server 8000 --directory sm-piano
# 브라우저에서 http://localhost:8000 접속
```

## 구글 폼 링크 연결하는 법

문의 폼이 아직 없어 "문의하기" 버튼이 임시로 비활성 상태입니다. 폼이 준비되면:

1. `index.html` 상단부, `<script>` 안의 이 줄을 찾는다.
   ```js
   const GOOGLE_FORM_URL = "";
   ```
2. 따옴표 안에 구글 폼 링크를 붙여넣는다. (예: `"https://forms.gle/xxxxxxx"`)
3. 저장 후 커밋·푸시하면, 페이지 안의 "문의하기" 버튼 3곳(헤더/히어로/하단)이 자동으로
   그 링크로 연결되고 새 탭에서 열립니다. 코드 수정은 이 한 줄이 전부입니다.

구글 폼 자체를 아직 안 만들었다면 `PRD.md`의 "진행 전 원장님이 해야 할 일" 항목(5단계)을 참고하세요.

## 아직 비워둔 것 (의도적)

- **수업료·분 단위 시간표** — 블로그 원문 안에서도 서로 어긋나거나 오래된 값이라 임의로 채우지
  않았습니다. "상담 시 안내"로 남겨두었으니, 확정되면 `#classes`(가격)·`#schedule`(시간) 섹션에 채워 넣으면 됩니다.
- **공간·악기 실제 사진** — 원장님 확인 전이라 SVG 건반 일러스트로 대체했습니다.
  사진 확보되면 `#space` 섹션의 `.keys-art` 블록을 `<img>`로 교체하세요.
- **아이들 사진** — 블로그에 있는 아이들 사진은 사용하지 않았습니다. 게시하려면 원장님과
  학부모 동의가 먼저 확인되어야 합니다.

## 디자인 메모

- 팔레트: 웜 아이보리 페이퍼(`--paper`) + 브라스(`--brass`, 피아노 금속 부속 톤) + 더스크
  네이비(`--dusk`, 야간 성인반 대비) + 카드 3색(rose/sage/sky, 작곡 카드 모티프).
- 이 교습소의 실제 차별점인 **카드 기반 작곡 수업**을 시각적 시그니처로 삼아, 히어로와
  `#composition` 섹션에서 "멜로디+리듬+화성=한 곡" 카드 조합 비주얼로 반복 사용했습니다.
  카드에 적힌 재료 이름(멜로디/리듬/화성/가사)은 일반적인 작곡 용어이며, 지식재산권 보호
  절차 중인 실제 카드 교재 내용은 노출하지 않았습니다.
- 폰트: 제목 Gowun Batang(고운바탕, 한글 세리프) / 본문 Pretendard / 시간표·수치 IBM Plex Mono.
- 모바일 최상단에서 스크롤 없이 히어로 헤드라인과 "문의하기" CTA(헤더 고정 버튼 포함)에
  도달하는 것을 Playwright로 확인했습니다(390×844 기준).
