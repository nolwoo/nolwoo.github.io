# 상명피아노음악교습소 — 홈페이지 시안

지인이 운영하는 인천 검단구 마전동 상명피아노음악교습소 홈페이지 **제안 시안**입니다.
자세한 배경·확인 목록은 [`PRD.md`](./PRD.md) 참고.

- **역할**: 유입은 네이버 블로그(`blog.naver.com/byeoldabang_mh`)와 네이버 플레이스가 담당하고,
  이 페이지는 그렇게 유입된 방문자를 실제 문의(구글 폼 제출)로 전환시키는 것만 담당합니다.
  검색 노출을 위한 작업(도메인, 네이버 웹마스터도구 등)은 범위 밖입니다.
- **구조**: 빌드 없는 정적 파일 `index.html` 하나. 원페이지 + 앵커 메뉴.

## 로컬에서 보기

```bash
python3 -m http.server 8000 --directory sm-piano
# 브라우저에서 http://localhost:8000 접속
```

## 구글 폼 연결 상태

문의 폼은 이미 연결되어 있습니다 — 페이지 안의 "문의하기" 버튼 3곳(헤더/히어로/하단)이
모두 `https://forms.gle/dXVtjDACwDSXRknW7`로 새 탭에서 열립니다(uni4eber@gmail.com 계정 소유,
응답은 연결된 구글 시트에 쌓이고 새 응답 이메일 알림도 켜둔 상태). 원장님 계정으로 옮기거나
폼 내용을 바꾸고 싶다면:

1. `index.html`에서 `data-cta-form` 대신 `href="https://forms.gle/..."`로 하드코딩된
   `<a class="btn btn-primary...">문의하기</a>` 3곳을 찾는다 (헤더/히어로/하단 문의 섹션).
2. 새 폼 링크로 각각 교체한다.
3. 저장 후 커밋·푸시. 이 3줄 교체가 전부입니다.

원장님을 폼·시트 공동작업자로 추가하려면 구글 폼 우측 상단 공유 아이콘에서
원장님 구글 계정 이메일을 추가하면 됩니다.

## 아직 비워둔 것 (의도적)

- **수업료·분 단위 시간표** — 블로그 원문 안에서도 서로 어긋나거나 오래된 값이라 임의로 채우지
  않았습니다. "상담 시 안내"로 남겨두었으니, 확정되면 `#classes`(가격)·`#schedule`(시간) 섹션에 채워 넣으면 됩니다.
- **아이들 사진** — 블로그에 있는 아이들 사진은 사용하지 않았습니다. 게시하려면 원장님과
  학부모 동의가 먼저 확인되어야 합니다.

## 사진 출처 — 원장님 확인 필요

`img/` 폴더의 사진 4장은 모두 원장님이 이미 블로그에 공개한 글의 사진입니다.
아이 얼굴이 없거나(공간·악기) 원장님이 직접 얼굴에 스티커로 가려 올린 사진(수료증)만
골라 썼지만, **실제 게시 전에는 원장님께 이 사진들을 계속 써도 되는지, 혹은 더 최근/더 좋은
사진으로 교체하고 싶은지 확인이 필요합니다.**

- `piano-room.jpg` · `piano-keys.jpg` · `sheet-music.jpg` — "음악공간을 소개합니다" 글
  (2025.11.11). 해당 글 촬영 시점이 2025년 11월이라 크리스마스 장식 등 계절감이 섞인 사진이
  포함돼 있어, 그중 계절 요소가 없는 3장만 골라 원본에서 여백·얼룩진 벽 모서리를 잘라내고 썼습니다.
  `piano-keys.jpg`는 히어로 배경으로 크게 쓰이면서, YAMAHA 로고·반사광이 들어간 원본 대신
  브랜드명이 걸려서 헤드라인 텍스트와 겹치지 않는 건반 전용 크롭으로 다시 골랐습니다.
- `certificate.jpg` — "1년의 창작 여정, 작곡수업 수료증 전달식" 글 (2026.3.5). 학생이
  작곡반(카드작곡) 수료증을 들고 있는 사진에서, 원장님이 직접 얼굴에 동물 스티커를 붙여
  가린 사진 중 수료증 문서만 보이도록 얼굴 부분을 제외하고 잘라 `#composition` 섹션에
  "실제로 발급하는 수료증" 증거 사진으로 사용했습니다.

## 디자인 메모

- 팔레트: 웜 아이보리 페이퍼(`--paper`) + 브라스(`--brass`, 피아노 금속 부속 톤) + 더스크
  네이비(`--dusk`, 야간 성인반 대비) + 카드 3색(rose/sage/sky, 작곡 카드 모티프).
- 이 교습소의 실제 차별점인 **카드 기반 작곡 수업**을 `#composition` 섹션에서
  "멜로디+리듬+화성=한 곡" 카드 조합 비주얼로 시그니처화했습니다.
  카드에 적힌 재료 이름(멜로디/리듬/화성/가사)은 일반적인 작곡 용어이며, 지식재산권 보호
  절차 중인 실제 카드 교재 내용은 노출하지 않았습니다.
  그 아래에는 실제 발급된 수료증 사진(`certificate.jpg`)을 작게 붙여, "이론이 아니라 실제로
  완성한다"는 주장을 추상적 그래픽에서 끝내지 않고 증거로 뒷받침합니다.
- 폰트: 제목 Gowun Batang(고운바탕, 한글 세리프) / 본문 Pretendard / 시간표·수치 IBM Plex Mono.
- **실제 사진 처리**: 공간 섹션의 사진에는 `.photo-frame` 클래스로 브라스 톤 color-grade(연한
  브라스 그라디언트를 `mix-blend-mode:multiply`로 겹침)를 적용해, 서로 다른 시점·조명에서 찍힌
  블로그 사진들이 한 팔레트로 보이도록 통일했습니다. 약간의 회전(-1~2도)과 그림자로 "출력해서
  올려둔 사진" 느낌을 냈습니다.
- **히어로 = 풀블리드 사진**: `be9`(benine9 studio) 제안 시안의 히어로 패턴(사진 전체를 배경으로
  깔고 하단에서 위로 어두워지는 그라디언트 위에 흰 글자를 얹는 방식)을 이 페이지에도 가져왔습니다.
  사진은 `piano-keys.jpg`(YAMAHA 로고 없는 건반 클로즈업)를 크게 씁니다. 텍스트 가독성은
  그라디언트(`--dusk` 계열, 하단 88%까지 어두워짐)와 헤드라인·리드 문구에 준 `text-shadow`로
  확보했고, `.hero-copy .btn-ghost`만 별도로 흰색 외곽선으로 오버라이드해 사진 위에서도
  버튼이 보이게 했습니다. 히어로 우측 상단에는 "네이버 블로그에서 소식 보기" 유리질감 pill
  링크(`.hero-topbar`)를 얹어, PRD의 "유입은 블로그, 전환은 이 페이지" 역할 분담과 반대로
  더 최신 소식이 궁금한 방문자는 언제든 블로그로 돌아갈 수 있게 열어 뒀습니다.
