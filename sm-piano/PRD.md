## 1. 이 페이지가 맡은 일 (가장 중요)

**유입은 블로그가, 전환은 이 페이지가 맡는다.**

```
네이버 검색 / 블로그 이웃 / 지역 카페
        ↓  (유입 — 블로그의 역할)
   블로그 글을 읽고 관심이 생긴 학부모
        ↓  (링크 한 번)
   ▶ 이 홈페이지 — 30초 안에 확신을 준다
        ↓
   문자 또는 카톡으로 상담 문의   ← 이 페이지의 성공 지표
```

**하지 않는 일 (명시적으로 범위 밖):**
- 검색 유입/노출 — `nolwoo.github.io/sm-piano/` 주소로는 네이버에 노출되지 않는다.
  검색 노출이 필요해지면 ① 도메인 구입 → ② 네이버 웹마스터도구·구글 서치콘솔 등록
  순서로 **별도 단계**에서 진행한다.
- 블로그 대체 — 소식·일상·수업 후기는 계속 블로그가 담당한다.
  이 페이지는 "지금 기준의 확정 정보"만 담는 **고정된 안내판**이다.
- 온라인 결제·수강 신청·회원가입 — 전부 범위 밖. 전환의 종착점은 문자 한 통이다.

### 이 페이지가 넘어야 할 전환 장벽

블로그를 읽고도 문의를 안 하는 이유는 대개 다음 5가지다. 각 섹션은 이 중 하나를 해소하는 역할을 갖는다.

| # | 학부모의 망설임 | 해소하는 섹션 |
|---|---|---|
| 1 | "여기가 정확히 뭘 가르치는 데지?" (글이 시간순으로 흩어져 있음) | 수업 과정 |
| 2 | "다른 피아노 학원이랑 뭐가 다른데?" | 작곡 클래스 |
| 3 | "우리 애 시간표랑 맞을까?" | 운영 시간 |
| 4 | "제대로 등록된 곳 맞나? 공간은 어떤가?" | 공간·악기 / 푸터 등록번호 |
| 5 | "지금 전화해도 되나… 부담스러운데" | 문의 CTA (문자·카톡 우선) |

## 2. 대상

- **1순위 — 검단·마전동 초등 학부모.** 블로그 유입의 대부분. 아이가 피아노를 시작하거나 옮길 곳을 찾는 중.
- **2순위 — 직장인 성인.** 야간반(19~22시)의 잠재 수요. 1순위와 필요한 정보가 다르므로 섹션 안에서 구분해 보여준다.
- 3순위 — 입시 준비생 학부모. 수는 적지만 확인이 안 되면 아예 문의하지 않으므로, 짧게라도 반드시 존재를 알린다.

## 4. 페이지 구성

빌드 없는 정적 단일 파일 `sm-piano/index.html` 하나. 상단 앵커 메뉴로 이동하는 원페이지.
모바일 우선 — 블로그 유입의 대부분이 모바일이다.

| 순서 | 섹션 | 담는 것 | 전환 역할 |
|---|---|---|---|
| 1 | 히어로 | "싱어송라이터가 지도하는 음악교실" / 검단·마전동 / 문자 문의 버튼 | 첫인상 + 즉시 전환 경로 |
| 2 | 소개 | 교육 철학 — 작은 성취가 음악을 즐기는 삶으로 이어지도록 | 신뢰 |
| 3 | 수업 과정 | 기본과정·성인부·입시반·작곡반 4개 카드 (대상/내용/교재) | 장벽 1 |
| 4 | **작곡 클래스** | 카드 작곡 교재, 한 수업 한 곡, 음원 제작 전 과정 | 장벽 2 — 가장 크게 |

| 7 | 위치·문의 | 지도, 마전역 2번 출구 도보 안내, 구글 폼 문의 CTA (+문자/전화 보조) | 장벽 5 |
| 8 | 푸터 | 정식 명칭, 등록 제995호, 블로그 링크 | 신뢰 |

### CTA 설계 — 구글 폼 문의 + 문자 보조

원장님이 블로그에서 반복해 밝힌 원칙: **"수업 중에는 통화가 어려우니 문자나 카톡으로 남겨주세요."**
다만 SMS는 한글 기준 약 45자로 문의 내용을 담기엔 짧아, **문의 접수는 구글 폼으로 받고
원장님은 나중에 구글 시트에서 확인**하는 방식을 택한다.

- 주 버튼: **"문의하기"** → 구글 폼 링크로 이동 (이름 / 연락처 / 관심 과정 / 문의 내용)
- 보조: 전화번호 텍스트 노출(복사용), 문자 바로가기(`sms:`), 이메일
- 폼 링크 **바로 옆에** "언제든 편하게 남겨주시면 확인 후 문자로 안내드립니다." 안내 문구.
- 히어로와 하단 문의 섹션 두 곳에 배치.
- **자체 DB·관리자 페이지는 만들지 않는다** — 정적 페이지 구조를 유지하기 위한 의도적 선택.
  bumil-safe식(Next.js + Supabase + Vercel + 관리자 인증)으로 가면 호스팅 방식 자체가 바뀌고
  계정 개설·환경변수·인증 등 유지보수 부담이 커져, 지인 시안 규모에는 맞지 않는다고 판단.
  구글 폼 + 구글 시트가 "문의 남기면 나중에 확인"이라는 목적을 동일하게 달성하면서
  코드/서버 추가가 전혀 없다.

**진행 전 원장님이 해야 할 일 (벤더 콘솔 작업 — 개발 아님):**
1. 구글 계정으로 `forms.google.com`에서 새 폼 생성 (5분 내외)
2. 항목: 이름 / 연락처 / 관심 과정(기본·성인·입시·작곡) / 문의 내용
3. 응답을 구글 시트로 자동 연결 (폼 만들 때 "응답" 탭에서 스프레드시트 아이콘 클릭)
4. 새 응답 알림 이메일 켜기 (스프레드시트 → 도구 → 알림 설정)
5. 완성된 폼의 "보내기" 링크를 이 PRD 작성자에게 전달 → `index.html`에 연결

### 블로그 연동

- 자동 연동(RSS 불러오기)은 **하지 않는다.** 정적 페이지에서 네이버 RSS를 직접 호출하면 브라우저가 차단한다(CORS).
- 대신 "블로그에서 더 보기" 링크 + 대표 글 2~3개를 손으로 골라 소개한다.

## 5. 디자인 방향

- **톤**: 정돈되고 절제된. 학원 전단지풍(원색·느낌표·번쩍이는 배지)은 피한다. 블로그 글의 결이 조용하고 다정하므로 장식을 덜어내는 쪽으로 그 결을 따른다.
- **색**: 완전 모노톤 — 거의 흰 종이(`--paper`)·연회색(`--paper-2`) 바탕에 짙은 먹색(`--ink`) 텍스트. 포인트 컬러 없이 명도 대비만으로 위계를 만든다. 카드·버튼은 각지게(radius 0), 그림자 없이 1px 보더로만 경계를 표시 — 건반의 흑백 대비를 그대로 차용한 결과다.
- **타이포**: 한글 본문 가독성 우선. 제목은 조금 크고 여백을 넉넉히.
- **줄바꿈 규칙**: `<br>`로 줄을 나눌 때 조사·접속사를 줄 끝에 남기지 않는다.
- **사진**: 이번 시안에서는 **공간·악기 사진 위주**로 구성한다. 블로그의 아이들 사진은 원장님과 학부모 동의가 확인되기 전까지 사용하지 않는다.

## 6. 시안 단계에서의 미확정 정보 처리

지인분께 세부 사항을 확인하지 않은 상태이므로, **블로그의 금액·시간을 그대로 옮겨 적지 않는다.**
(블로그 안에서도 서로 어긋나고, 일부는 최대 9개월 전 정보다.)

- 수업료: 페이지에 금액을 넣지 않고 **"수업료는 과정별로 상담 시 안내드립니다"**로 처리한다.
- 시간표: 요일·시간대의 **구조**만 보여주고(예: 학생부 오후, 성인부 야간, 수요일 작곡), 분 단위 시간은 넣지 않는다.
- 확정되면 해당 자리에 그대로 채워 넣을 수 있게 마크업을 구성한다.

### 원장님 확인 목록 (시안 전달 시 함께 드릴 것)

1. 작곡반 수업 시간 — 모집 글은 수요일 2:00/3:30/5:00, 1월 일정표는 오후 3~6시로 서로 다름
2. 수업료 현행값 — 성인부 월 200,000원(2025.11 기준), 작곡 신규 월 75,000원(2026.3 기준)
3. 피아노 기본과정 수업료 — 블로그에 없음
4. 운영 시간 — 월·화·목·금 14~19시(학생) / 19~22시(성인), 수요일 작곡. 현행 여부
5. 사진 사용 범위 — 아이들 사진 게시 가능 여부 및 학부모 동의 여부
6. 네이버 플레이스 / 카카오톡 채널 계정 유무 — 있으면 CTA로 연결
7. 홈페이지에 수업료를 공개할지 여부 (공개 시 전환율은 오르지만 변경 때마다 수정 필요)
