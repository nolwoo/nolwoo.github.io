# 하나의숲 (One Forest) 홈페이지 PRD

> 문서 상태: 1차 초안
>
> 참고: 제공된 Instagram 게시물은 외부 접근 제한으로 본문과 이미지를 직접 검증하지 못했다. 아래의 상점 정보는 현재 프로젝트에 정리되어 있던 내용을 기준으로 하며, 실제 게시물/운영 정보 확인 후 확정한다.

## 1. 개요

- **상점명**: 하나의숲 (One Forest) — 구 돌고래상점
- **업종**: 제로웨이스트샵 + 독서모임 + 생태교육
- **위치**: 화성시 봉담읍 진등2길 13 (봉담초 정문 앞)
- **운영**: 평소 무인 운영
- **오픈 일정**: 임시오픈 2026-04-22(지구의 날), 정식오픈 2026-05-09(토)
- **슬로건**: "읽고, 쓰고, 자연을 만나는 곳 🌿"
- **SNS**: Instagram [@one.forest_](https://www.instagram.com/one.forest_/)

홈페이지는 상점을 처음 접하는 동네 주민/방문객이 **제품과 프로그램을 보고 신청까지 이어지도록** 안내하는 것이 목적이다. 온라인 결제나 실시간 재고 관리는 하지 않는다 (무인 매장 특성상 현장 결제/이용이 기본).

## 2. 목표 우선순위

1. **제품 소개** (최우선) — 제로웨이스트 상품 라인업을 사진과 함께 소개
2. **프로그램/모임 홍보 및 신청** (최우선) — 수공예 모임, 원데이클래스, 독서모임(책숲), 생태교육(탐험대) 일정 안내 + 신청
3. 상점 소개 & 오시는 길 — 기본 정보로서 모든 페이지에 걸쳐 제공 (별도 우선순위는 아니지만 필수)
4. 브랜드 스토리 — 이번 범위에서는 홈 화면 소개 문구 수준으로만, 별도 페이지는 만들지 않음

## 2-1. 문제 정의

현재 상점 정보가 Instagram 게시물과 DM에 흩어져 있어, 처음 방문하는 사람은 다음 정보를 한 번에 확인하기 어렵다.

- 어떤 상품을 판매하는지
- 어떤 프로그램이 언제 열리는지
- 무인 운영 매장을 어떻게 이용하는지
- 매장 위치와 문의 방법이 무엇인지

홈페이지는 Instagram을 대체하는 채널이 아니라, Instagram에서 유입된 방문자가 **방문·신청에 필요한 정보를 빠르게 확인하는 공식 안내 허브**로 기능한다.

## 2-2. 핵심 사용자

1. **동네 방문자**: 제로웨이스트 상품을 구경하거나 구매하기 위해 위치·운영 방식을 확인하는 사람
2. **프로그램 참여 희망자**: 독서모임, 생태교육, 수공예/원데이클래스의 내용과 일정을 보고 신청하려는 사람
3. **Instagram 유입 방문자**: 게시물에서 링크를 눌러 상점의 전체 정보와 최신 안내를 확인하려는 사람

## 2-3. 대표 사용자 흐름

### 상품 구매를 원하는 방문자

`Instagram/검색 유입 → 홈 → 제품 소개 → 관심 상품 확인 → 매장 위치·운영 방식 확인 → 방문`

### 프로그램 신청을 원하는 방문자

`Instagram/홈 유입 → 프로그램 목록 → 프로그램 상세·일정 확인 → 신청 폼 제출 → 이메일 알림/운영자 회신`

### 처음 방문하는 사람

`홈 → 상점 한 줄 소개 → 무인 운영 안내 → 오시는 길 → 지도 앱으로 길찾기`

## 3. 사이트 구조 (다중 페이지, GitHub Pages 정적 사이트)

`nolwoo.github.io/one-forest/` 하위에 정적 HTML 4장:

| 파일 | 페이지 | 핵심 내용 |
|---|---|---|
| `index.html` | 홈 | 히어로(슬로건+사진), 상점 한 줄 소개, 제품/프로그램 하이라이트, 오픈 일정 배너, 퀵링크 |
| `products.html` | 제품 소개 | 제로웨이스트 상품 카테고리 및 대표 상품 사진+설명, 구매 문의는 인스타 DM 안내 |
| `programs.html` | 프로그램/모임 | 정기 모임(수공예/독서모임/생태교육) + 원데이클래스 목록과 일정, 신청 폼 |
| `visit.html` | 오시는 길 & 문의 | 주소, 지도(임베드), 영업시간, 무인운영 안내, 문의 폼 |

공통 네비게이션 바 + 푸터(주소/인스타 링크)로 4개 페이지를 연결.

### 페이지별 필수 CTA

| 페이지 | 주 CTA | 보조 CTA |
|---|---|---|
| 홈 | 제품 보러가기 / 프로그램 확인하기 | 오시는 길, Instagram |
| 제품 소개 | 매장 방문 안내 | Instagram DM 문의 |
| 프로그램/모임 | 프로그램 신청하기 | Instagram에서 최신 일정 확인 |
| 오시는 길 & 문의 | 지도 앱으로 길찾기 | 문의 보내기, Instagram |

## 4. 신청/문의 폼

- **방식**: 별도 서버 없이 정적 사이트에서 바로 이메일로 전송되는 폼 서비스 사용 — **Formspree** (무료 티어로 충분, 월 50건)
  - 사용자가 Formspree 계정을 만들고 폼 엔드포인트를 발급받아야 함 (가입 필요, 무료)
- **프로그램 신청 폼** (programs.html): 이름, 연락처(전화/카톡ID), 신청 프로그램(드롭다운), 희망 날짜, 인원수, 메모
- **문의 폼** (visit.html): 이름, 연락처, 문의 내용
- 제출 시 상점 이메일로 알림, 폼 자체에 "영업시간 내 무인 운영이라 답변은 인스타 DM 또는 이메일로 드려요" 안내 문구 추가

### 폼 UX 요구사항

- 모바일에서 한 손으로 입력하기 쉬운 단일 열 레이아웃
- 필수 입력값과 입력 오류를 명확히 표시
- 제출 성공/실패 상태를 페이지 안에서 즉시 안내
- 개인정보 수집 목적과 문의 응답 용도를 짧게 고지
- 스팸 방지를 위한 Formspree 기본 기능 또는 간단한 허니팟 필드 검토

## 5. 지도

- **카카오맵 JS SDK 임베드** (visit.html에 실제 지도 표시)
  - 사용자가 카카오 디벨로퍼스에서 앱 등록 후 JavaScript 키 발급 필요 (무료)
  - 발급 전까지는 정적 이미지/링크로 대체 가능
- 주소 텍스트 + "카카오맵/네이버지도 앱에서 길찾기" 외부 링크도 함께 제공

## 6. 디자인 톤

- 자연친화적, 따뜻한 무드 — 그린/브라운/크림 계열 팔레트
- 이모지 활용 (🌿🧺📚✂️💛) — 인스타그램 톤과 일관성 유지
- 실제 상점/제품 사진 필요 (인스타그램에서 가져오거나 사용자가 별도 제공)
- 반응형(모바일 우선) — 동네 주민들이 휴대폰으로 볼 가능성이 높음

## 7. 기술 스택

- 순수 HTML/CSS/JS, 빌드 없음 (repo의 다른 정적 앱들과 동일한 패턴)
- 데이터 저장 없음(로그인/개인정보 저장 없음) — 폼 제출은 Formspree로 바로 전송
- 배포: `git push` → GitHub Pages 자동 반영 (`nolwoo.github.io/one-forest/`)

## 7-1. 비기능 요구사항

- 모바일 우선 반응형: 360px 이상 화면에서 핵심 콘텐츠와 CTA 사용 가능
- 접근성: 충분한 색상 대비, 이미지 대체 텍스트, 키보드 포커스, 명확한 링크 문구
- 성능: 이미지 lazy-loading 및 적정 크기 압축, 첫 화면에서 불필요한 외부 스크립트 최소화
- SEO: 페이지별 title/description, Open Graph 메타 태그, 주소·상점명 텍스트 노출
- 유지보수: 상품과 프로그램 콘텐츠를 HTML에서 쉽게 찾고 수정할 수 있는 구조
- 외부 서비스 장애 시에도 주소, 운영 안내, 기본 상품/프로그램 정보는 열람 가능

## 7-2. 성공 지표 (MVP 기준)

- 방문자가 첫 화면에서 제품, 프로그램, 위치 중 하나로 1회 이상 이동
- 프로그램 신청 폼 제출이 정상적으로 운영자 이메일에 도착
- 모바일에서 주소·운영시간·무인 이용 안내를 2탭 이내에 확인
- 배포 후 주요 페이지에 깨진 링크나 가로 스크롤이 없음

## 8. 진행 전 확인 필요 사항 (사용자 준비물)

- [ ] 실제 제품 사진/설명 (또는 인스타 사진 사용 동의)
- [ ] 프로그램별 정확한 가격 (현재 인스타에 명시 안 됨)
- [ ] Formspree 계정 + 폼 엔드포인트
- [ ] 카카오 디벨로퍼스 JavaScript 키 (지도용)
- [ ] 상점 이메일 주소 (문의 알림 받을 곳)

### 콘텐츠 확정 질문

- [ ] 상점의 공식 표기명과 로고/프로필 이미지
- [ ] 실제 운영시간, 무인 이용 방법, 결제 수단
- [ ] 제품 카테고리·대표 상품·가격 공개 여부
- [ ] 프로그램별 일정, 정원, 참가비, 신청 마감 방식
- [ ] 홈페이지에서 사용할 사진의 원본 파일 및 사용 권한
- [ ] 개인정보 처리 안내 문구와 문의 응답 예상 시간

## 9. MVP 수용 기준

- [ ] 홈에서 상점 정체성, 대표 이미지, 제품/프로그램/방문 CTA를 확인할 수 있다.
- [ ] 제품 페이지에서 카테고리와 대표 상품 정보를 확인할 수 있다.
- [ ] 프로그램 페이지에서 프로그램별 설명·일정·신청 버튼을 확인할 수 있다.
- [ ] 신청 폼은 모바일에서 제출 가능하고, 성공/실패 상태를 사용자에게 보여준다.
- [ ] 방문 페이지에서 주소, 지도, 운영시간, 무인 운영 안내, 문의 방법을 확인할 수 있다.
- [ ] 네 페이지의 네비게이션과 푸터 링크가 서로 연결된다.
- [ ] 외부 지도/폼 키가 아직 없는 환경에서도 대체 링크 또는 안내 문구가 노출된다.
- [ ] 360px~1440px 범위에서 레이아웃이 깨지지 않는다.
