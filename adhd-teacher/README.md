# 학생 행동 관찰 노트 (교사용)

교사가 교실에서 관찰한 학생의 언행을 기록하면, 그 기록을 근거로 **지켜볼 단계인지 ·
교실 지원을 시작할 단계인지 · 보호자 상담이 필요한 단계인지**를 정리해 주는 도구입니다.
진단 도구가 아니며, ADHD 진단은 소아청소년정신과 전문의만 내릴 수 있습니다.

같은 폴더의 `adhd-screener/`(부모용 원본)를 교사용으로 고쳐 만들었습니다. 원본은 그대로 둡니다.

## 부모용 원본과 달라진 점

원본의 증상 문항(DSM-5-TR 18개)·채점 규칙(Vanderbilt)·단계 기준은 그대로 두되,
**교사가 확인할 수 없는 것을 확인한 척하지 않는다**는 원칙으로 세 곳을 바꿨습니다.

| | 부모용 원본 | 교사용 |
|---|---|---|
| **진단기준 C** (2가지 이상 상황) | 가정+학교로 충족 판정 | **미확인으로 표시** — 삭제도 자동충족도 하지 않음 |
| 최상위 단계의 세 번째 관문 | 기준 C 충족 | 학교 생활에서의 **기능 손상**(교사가 관찰 가능) |
| 최상위 단계의 권고 | "전문 평가를 예약하세요" | **"교내 상의 → 보호자 상담"** (교사는 병원 예약을 할 수 없음) |
| 부모 성향 체크 (ASRS v1.1) | 있음 | **제외** — 보호자가 자신에 대해 답하는 성인 자기보고 척도라 교사가 대신 답할 수 없음 |
| 상황 체크 | 부모가 전부 답함 | **교사 확인 가능 / 보호자만 아는 항목**을 분리하고 '모름'을 기본값으로 |
| 학대·따돌림 의심 | 점수에 반영되는 체크박스 | **신고 안내 UI로 전환** (아래 참고) |
| 행동 지침 | 부모 행동훈련·병원 예약·약물 원칙 | **교실 환경 조정 · 교내 자원 연계 · 보호자 상담 준비** |
| 서버 동기화 | Supabase + 종단간 암호화 | **제거** — localStorage만, 백업은 JSON 파일 |

### 왜 기준 C를 삭제하지 않았나

교사가 관찰하는 수업·쉬는 시간·이동은 **모두 '학교'라는 한 상황 안의 장면**이라, 아무리
많이 기록해도 DSM-5-TR 기준 C는 충족되지 않습니다. 그렇다고 이 요건을 지워버리면 판정이
원본보다 **더 공격적**으로 바뀝니다 — 관문 하나가 사라지는 셈이니까요. 그래서 삭제 대신
"미확인"으로 표시하고, 판정 카드마다 그 한계를 함께 띄웁니다.

같은 이유로 상황 체크의 수면·생활변화 항목도 지우지 않았습니다. 이 항목들은 ADHD처럼
보이는 다른 원인을 걸러내는 **안전장치**라서, 없애면 수면 부족인 학생이 그대로 상위 단계로
올라갑니다. 대신 '모름'을 기본값으로 두고, 미확인 상태 자체를 판단에 표시합니다.

### 왜 학대 의심은 체크박스가 아닌가

「아동학대범죄의 처벌 등에 관한 특례법」 제10조에 따라 **교원은 신고의무자**이며, 직무
수행 중 아동학대범죄를 알게 되거나 **의심이 있는 경우** 시·도, 시·군·구 또는 수사기관에
즉시 신고해야 합니다(신고전화 112). 확증은 필요하지 않고, 정당한 사유 없이 신고하지
않으면 과태료가 부과됩니다. 즉 이건 **기록해서 판단에 반영할 항목이 아니라 즉시 행동할
항목**이라, 체크박스 대신 신고 절차를 안내하는 별도 UI로 두었습니다.

관련 도구: `teacher-guard/`(교실 나침반) — 반대로 *교사 자신의* 생활지도가 아동학대에
해당할 수 있는지를 판례 기준으로 점검합니다.

## 교사가 지켜야 할 선 (UI에도 반복해서 표시)

- **진단명을 말하지 않습니다.** 보호자에게 전달할 것은 관찰된 행동과 빈도이며, 해석과
  결정은 보호자·전문의의 몫입니다. 이 도구의 어떤 문구도 교사가 "ADHD인 것 같다"고
  말하도록 유도하지 않습니다.
- **학교생활기록부가 아닙니다.** 교사의 추정이 섞여 있으므로 공식 기록에 옮겨 적지 않습니다.
- **백업 파일을 전달하지 않습니다.** 학급 전체 학생의 기록이 함께 들어 있습니다.
- **이름 대신 번호·별명**으로 등록하도록 권합니다 (학생 건강 관련 추정이 담기는 기록).

## 데이터

모든 기록은 **사용자 브라우저의 localStorage에만** 저장되며 서버로 전송되지 않습니다.
기기 간 이동은 앱의 JSON 내보내기/가져오기를 사용하세요. 가져오기는 기존 기록을 지우지 않고
새 항목만 합칩니다.

## 근거

DSM-5-TR, ICD-10, AAP 2019 진료지침, NICE NG87, Evans 2018(교실 행동 개입),
K-ARS 표준화 연구(소유경 2002, 김영신 2003), Faraone 2019·2021(유전율) 등 —
전체 목록은 앱의 "근거와 한계" 탭 참고. 저작권이 있는 상용 척도(Conners 등)는 쓰지 않았습니다.

## 배포

정적 단일 파일(`index.html`)이라 빌드 과정이 없습니다. 이 저장소를 `main`에 push하면
GitHub Pages로 `nolwoo.github.io/adhd-teacher/`에 배포됩니다.

**검색 비노출로 두었습니다** — `<meta name="robots" content="noindex, nofollow">`.
주소를 아는 사람은 들어올 수 있지만 검색 결과에는 뜨지 않습니다. 공개로 바꾸려면 그 한 줄을
지우면 됩니다.

## 로컬에서 보기

```bash
python3 -m http.server 8899 --directory adhd-teacher
```

포트를 바꾸면 브라우저가 다른 사이트로 인식해 **저장한 기록이 보이지 않습니다**
(localStorage는 포트까지 포함한 출처 단위로 분리됨). 8899로 고정해서 쓰세요.
